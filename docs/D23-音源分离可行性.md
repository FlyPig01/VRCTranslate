# D23：音源分离可行性实验 —— ❌ 不可行，不实施

> **状态：实验完成（2026-09-16），结论「不做」**。
> 目的：验证「两个人同时说话丢一路」有没有救——**先验证，不先写代码**。

## 0. 结论

| 检查项 | 结果 |
| --- | --- |
| sherpa-onnx 自带分离模型能拆「两个人声」吗 | ❌ **不能**。它只提供 **Spleeter / UVR**，都是**音乐伴奏分离**训练出来的，两路都是「vocals」时不会拆开 |
| sherpa-onnx 的分离接口在本机可用吗 | ❌ **跑不通**：用官方 `csukuangfj/sherpa-onnx-spleeter-2stems` 模型，`OfflineSourceSeparation.process()` 报 `ComputeStft: Invalid channel 1. Max 1`（1.13.8，本机） |
| 换人声专用模型（SepFormer）可行吗 | ⚠️ **需要 Python + PyTorch 栈**（torch 2.14 + speechbrain 1.1 + 41 MB 权重），**与项目「纯 .NET + onnxruntime」架构冲突**；且**没有 ONNX 可用版本** |
| 若真能分离，延迟可接受吗 | ❌ **大概不可接受**：这类模型按块推理，要凑够一块（SepFormer 训练块 4 s）才开始算；即使 RTF 很优，字幕也要多等**数秒** |

**⇒ D23 关闭：不做。** 同时**保持现状**（保一路）——「宁可漏一个人，也不要出乱码」。

## 1. 实测记录

### 1.1 sherpa-onnx 的分离接口（本机 1.13.8）

```
模型：csukuangfj/sherpa-onnx-spleeter-2stems（vocals.onnx 37.5 MB + accompaniment.onnx 37.5 MB）
调用：sherpa_onnx.OfflineSourceSeparation.process(sample_rate=16000, samples=(1,N) float32)
结果：日志显示先重采样 16k→44.1k，随后 
      offline-source-separation-spleeter-impl.h:ComputeStft:196 Invalid channel 1. Max 1
```

排查过的点：一维/二维输入、采样率用 int 还是 float、声明 44.1k——错误一致，说明是**本机构建与该模型的通道约定不匹配**，非调用姿势问题。

> 但这一点**不影响结论**：即使接口跑通，Spleeter 的输出是「vocals + accompaniment」，
> 对「两个都是人声」的输入，两路都算 vocals，**不会把两个人拆开**。

### 1.2 人声专用模型（SepFormer-WHAMR）

- 权重可从镜像取到（`speechbrain/sepformer-whamr`，masknet.ckpt 41.4 MB）；
- 但 `speechbrain` 在 Windows 上用 symlink 装载模型，**本机无该权限**（`WinError 1314`）；手动下载 ckpt 绕过时，`encoder.ckpt` / `decoder.ckpt` 只有 17 KB 且 `torch.load` 报 zip 损坏——**该路线需要额外的工程投入**（手工校验权重、绕开 speechbrain 装载器）；
- 更重要：**它是 Python + PyTorch 生态**。项目现在是「C# + onnxruntime + sherpa-onnx」，引入它等于**换掉一半技术栈**，为一个「可能几秒延迟」的功能。

### 1.3 延迟账（为什么即使能分离也不划算）

| 环节 | 代价 |
| --- | --- |
| 分块推理的固有延迟 | SepFormer 这类模型按训练块（**4 s**）处理，要凑够一块才出结果 ⇒ 字幕至少晚**数秒** |
| 额外 CPU | 分离模型常驻推理，与 SenseVoice、CAM++ 抢 CPU |
| 包体 | 40~80 MB 起（不含 PyTorch） |

而现在的问题是「字幕已经要等 0.8~1.7 s」——**再加几秒本质上是把功能做废**。

## 2. 因此 D23 的处理

| 项 | 决定 |
| --- | --- |
| 是否实施 | **否** |
| 重叠丢一路 | 维持「保一路」，作为产品边界记录在 《模型能力边界.md》§1 |
| 若将来真要解 | 前提是出现**可在 onnxruntime 里跑、且块长 ≤1 s** 的人声分离模型；那时再评估 |
