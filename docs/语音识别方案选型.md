# 语音识别方案选型（记录）

日期：2026-09-13。数据来源：《多语言全链路质量与性能测试报告》（V1 实测）与各服务商官方文档。

> **状态更新（2026-09-13）**：决策改为**本地 SenseVoiceSmall INT8 全量替换**（见《SenseVoice本地替换实施方案》），云 API 一律**暂缓**——本地模型已覆盖中/粤/英/日/韩主线，免费 API 无增量收益；待本地链路验收后再评估法德西俄等扩展语言的云端补充。

## 1. API 选型（国内供应商，暂缓）

**决策：优先 `FunAudioLLM/SenseVoiceSmall`（硅基流动 SiliconCloud，免费）。**

| 服务 | 模型 | 能力 | 语言 | 费用 |
|---|---|---|---|---|
| 硅基流动 SiliconCloud | FunAudioLLM/SenseVoiceSmall | 语音识别（ASR）+ 情感/事件检测 | 中、粤、英、日、韩 | **免费** |
| 硅基流动 SiliconCloud | TeleAI/TeleSpeechASR | 语音识别 | 中文方言向 | 免费 |
| 硅基流动 SiliconCloud | FunAudioLLM/CosyVoice2-0.5B | **语音合成（TTS），不能用于识别** | 多语言 | 付费 |
| 腾讯云 / 阿里云 | 实时语音识别 | 流式 WebSocket，边说边出字 | 多语种（含法德西俄） | 有免费额度，超出按量 |
| 阿里云 | sensevoice-v1（闭源版） | 语音识别 | 官方称 50+ 语言 | 约 ¥0.44/秒起 |

- 接入方式：`POST https://api.siliconflow.cn/v1/audio/transcriptions`，OpenAI 兼容协议，国内节点直连。
- 注意：CosyVoice2 是"文字转语音"，与识别方向相反，仅当未来需要"把译文读出来"时才用（付费）；识别一律选 SenseVoiceSmall。
- 法/德/西/俄不在 SenseVoiceSmall 覆盖内，需要时由腾讯云/阿里云流式 ASR 或本地 Whisper small 补位。

## 2. 本地部署：各方案性能与存储占用（V1 实测）

| 方案 | 中/英/日/韩错误率 | RTF | P50 / P95 | 内存增量峰值 | 模型+运行库体积 |
|---|---|---|---|---|---|
| **SenseVoiceSmall INT8（sherpa-onnx）** | 4.9% / 10.0% / 5.8% / 6.4% | 0.021~0.028 | 174~207 ms / 233~259 ms | 324~356 MiB | 255.3 MiB |
| Whisper base q5_1（V2 现状） | 31.6% / 13.8% / 24.7% / 14.6% | 0.079~0.103 | ~750 ms / ~810 ms | 167 MiB | 69.4 MiB |
| Whisper small q5_1 | 25.6% / 9.7% / 15.7% / 9.1% | 0.275~0.352 | ~2.5 s / ~2.7 s | 361 MiB | 193.8 MiB |

结论（沿用报告）：中英日韩主线必须 SenseVoice；whisper.cpp 不能替换 SenseVoice；Whisper small 仅作为西语等扩展语言的实验组件（法德俄噪声下不可用）。

## 3. GPU 加速结论

**应用环境为 VRChat，游戏本身占用大量 CPU，识别推理不应再抢 CPU——GPU 卸载有必要。**

关键事实：**GPU 接口不是自由选择，而是由推理引擎决定的**：

| 引擎 | 对应模型 | 可用的 GPU 后端 | 部署代价 |
|---|---|---|---|
| ONNX Runtime（sherpa-onnx） | SenseVoice | **DirectML**（DirectX 12）或 CUDA | DirectML 随显卡驱动，N/A/Intel 卡通用，增补约 35 MB（onnxruntime.dll + DirectML.dll） |
| whisper.cpp / GGML（Whisper.net） | Whisper | **Vulkan** 或 CUDA | Vulkan 随驱动，N/A/Intel 通用，增补几 MB；CUDA 仅 N 卡且需捆绑 cuBLAS（体积大） |

- 主线（SenseVoice）走 **DirectML**：开发机为 RTX 4060 Laptop + AMD 780M，两者都支持；推理从 CPU 迁到 GPU 后，CPU 占用归零、单句耗时可望从 ~186 ms 降至几十毫秒量级（待实测）。
- 扩展语言（Whisper small）走 **Vulkan**：whisper.cpp 没有 DirectML 后端，这是唯一"随驱动"的选项；预期把 2.5 s/句降到 1 s 内。
- CPU 回退保留：无独显/驱动异常时自动落回 CPU 路径。

## 4. 实施路线（待排期）

1. V2 识别器新增 SenseVoice 实现（Sherpa.Onnx + DirectML EP，CPU 回退），替换 Whisper 主线地位；

4. 全部落地后按本档案数据回归验证。
