## 0. 文档约定

本目录只放**现行有效**、**单一职责**的文档。四条规则：

| 目录 | 放什么 |
| --- | --- |
| `docs/`（本层，**只 5 份**） | 索引（本文）、约束、缺陷账、实验记录、能力边界与决策 |
| `docs/evidence/` | **原始数据**（评测集、逐条记录），供复核；不是叙述文档 |
| `docs/archive/` | 已实施/已被取代的**历史文档**，正文一字不改，只在顶部加说明块 |
| `artifacts/` | 发布包、测试素材、复现脚本（**不入库**，见 `artifacts/README.md`） |

**写新文档前先问**：能不能并进现有 5 份之一？能就别新建。

## 2. ⚠️ 测试口径时间线（**看数据前必读**）

同一个指标在不同文档里数字不同，多半是**口径不同**，不是谁写错了：

| 时间 | 出处 | 实测对象 | 口径（关键差异） | 结论 |
| --- | --- | --- | --- | --- |
| 2026-07-21 | `archive/多语言全链路质量与性能测试报告.md` | V1（v0.10.0，**含 OCR**） | 九语言 OCR + 八种口语 ASR + 三个付费档案；**OCR 已不在 V2 范围** | 中英日韩用 SenseVoice；需通用不变量保护 |
| 2026-09 | `archive/DeepSeek翻译实测.md` | 直连 DeepSeek API（**脚本**） | **单次调用、单目标语言、不含 VAD、不含 OSC**；旧系统提示 | 中位约 900 ms；思考模式不值得开 |
| 2026-09-15 | `archive/翻译服务软件内实测对比.md` | **软件内**（UIA 驱动真实进程） | **按 Enter → 收到 OSC 报文**；每句**两个目标语言** | DeepSeek 1590 ms、小米 2553 ms（含两次串行） |
| 2026-09-15 夜 | 同上 §5.1(5) | 同上，**并行化之后** | 同上，两个目标并发 | DeepSeek **1031 ms**、小米 **1356 ms** |
| 2026-09-16 | [实验记录-识别与翻译.md](实验记录-识别与翻译.md) | **他人语音链路**（反射直调，不经 UI） | **识别与翻译分开计时**；翻译＝单次 HTTP 调用；质量＝对人工参考译文的 chrF2/BLEU-4 | 机翻 195~269 ms、大模型 495~696 ms；同时讲话无法识别 |

**一句话记法**：旧文的 ~900 ms ＝ **模型单次调用**；新文的 1590 → 1031 ms ＝ **按 Enter 到 VRChat 收到消息**。两者不能直接比大小。

**语音链路还要多一段**：VAD 判定「说完了」要等 **600 ms 静音**，所以「说完话 → 字幕出现」≈ 0.6 s + 0.14 s + 翻译时间（详见 [能力边界与决策记录.md](能力边界与决策记录.md) §4）。

## 3. 发布手测包的两条硬要求（踩过坑）

1. **必须清空输出目录再发布**，否则会混进上一次的产物：
   ```powershell
   Remove-Item -Recurse -Force artifacts\manual-test
   dotnet publish src/VrcTranslate.Desktop/VrcTranslate.Desktop.csproj -c Release `
     -p:Platform=x64 -r win-x64 --self-contained true -o artifacts/manual-test
   ```
   症状：`dotnet publish -o` **不会清空**目标目录；一次不带 `--self-contained` 的发布会把**框架依赖版**的
   `VrcTranslate.runtimeconfig.json` 留下，和自包含的 `coreclr.dll` 混在一起，双击就弹「You must install or update .NET」。
   **自检**：干净的包，`VrcTranslate.runtimeconfig.json` 里应是 `includedFrameworks`（带版本号），**不是** `framework`。
2. **发布后必须重铺 `data` 目录**（档案/密钥在里面，发布不会带走）：
   ```powershell
   pwsh -NoProfile -ExecutionPolicy Bypass -File artifacts\seed-profiles.ps1
   ```
   该脚本会在 `artifacts\profile-backup\` 留备份，密钥来源按「备份 → 包内 → 用户目录」回退；缺任何一家都会**明确报错而不是写半份档案**。
   另外**发布前先关掉正在运行的软件**，否则文件被占用会导致发布失败（exe 保持旧时间戳）。
