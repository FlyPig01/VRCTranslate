# 小米 MiMo 模型清单与选型依据

日期：2026-09-15 · 本机 · 通过**平台官方文档 + 真实 API 调用**核对（不是只看文档）

配套阅读：`docs/翻译服务软件内实测对比.md`（软件内实测，两个提供商的端到端延迟对比）。

## 1. 平台上有哪些模型

| 模型 ID | 类别 | 能力 | 我们能不能用 | 实测结果 |
| --- | --- | --- | --- | --- |
| `mimo-v2.5` | 文本 / 多模态 | 文本生成、深度思考、流式、函数调用、结构化输出、联网搜索 | ✅ **已接入（默认）** | 3 句翻译 **684 / 1149 / 2126 ms** |
| `mimo-v2.5-pro` | 文本（旗舰推理） | 同上，推理更强 | ✅ 可调用，**不推荐** | 3 句翻译 **1682 / 2026 / 2326 ms** |
| `mimo-v2.5-asr` | 语音识别 | 中英 + 方言、非流式 | ❌ 不接（见 D12） | 0.5 元/小时，但非流式且丢说话人区分 |
| `mimo-v2.5-tts` / `-tts-voiceclone` / `-tts-voicedesign` | 语音合成 | 3 个 TTS 变体 | ❌ 本项目不需要 | 限时免费 |
| `mimo-v2-pro` / `mimo-v2-flash` / `mimo-v2-omni` | 上一代 | — | ❌ **已无法调用** | 真实请求返回 **HTTP 400**，官方文档标注 2026-06-30 下线 |

> 结论：**能用于翻译的只有 v2.5 这一代的两个文本模型**（`mimo-v2.5` 与 `mimo-v2.5-pro`）。
> 上一代 v2 系列我拿真实 Key 试过，三个模型全部 400，文档里也写着已下线，所以"更多模型可选"实际上是**二选一**。

## 2. 为什么默认选 `mimo-v2.5`（非 pro）

| 依据 | `mimo-v2.5` | `mimo-v2.5-pro` |
| --- | --- | --- |
| 实测延迟（3 句同一批，关闭思考） | 684 / 1149 / 2126 ms | 1682 / 2026 / 2326 ms |
| 相对速度 | 基准 | **慢 1.4 ~ 3.4 倍**（句子越短差距越大） |
| 译文质量（同一批样本） | 嘿，小心，那棵树后面藏着一个玩家！ | 嘿，小心，那棵树后面藏着一个玩家！（**逐字相同**） |
| 计费权重（官方 Credit 表，输入/输出） | 100 / 200 | **300 / 600（3 倍）** |
| 官方定位 | 全能多模态主力 | 旗舰推理（复杂推理/代码/数学） |

两个理由：

1. **翻译用不上推理**。pro 的溢价买的是"想得更久"，而"把一句日语翻成中文"不需要推理链；
   同一批样本里两家（v2.5 与 pro）译文**逐字相同**，付 3 倍价钱换不到东西。
2. **字幕是实时场景**。pro 的延迟是 2~3 秒级（软件内实测 median 3.4 秒/次调用），
   而 `mimo-v2.5` 也在 0.7~2.1 秒，已经比 DeepSeek 慢；再上 pro 会直接不可用。

## 3. 价格（能查到的部分与查不到的部分，分清楚）

| 项 | `mimo-v2.5` | `mimo-v2.5-pro` |
| --- | --- | --- |
| 输入 | **0.7 元 / 百万 tokens**（公开报道，如 [IT之家](https://www.ithome.com/0/914/844.htm)） | 官方未公开（计费权重是 v2.5 的 **3 倍**） |
| 输出 | 未见公开数字 | 官方未公开（权重 3 倍） |
| 计费权重（官方 [Token Plan 文档](https://mimo.mi.com/static/docs/quick-start/faq/token-plan.md)） | 输入 100 / 输出 200 Credits | 输入 300 / 输出 600 Credits |
| 折扣 | 首次购买 12% 折扣；0:00-8:00 时段系数 0.8x | 同 |
| 套餐 | Lite / Standard / Pro / Max（月/年），Lite 约 39 元/月 | 同（共用同一份 Credits） |

**诚实说明**：小米的官方价格页（`platform.xiaomimimo.com/#/docs/pricing`）**需要登录**，
我无法从公网核对完整价目表；上表里"0.7 元/百万 tokens"来自公开报道，**pro 的具体单价我没有可靠来源**，
只用官方 Credit 权重说明"pro 的单价是 v2.5 的 3 倍"这一相对关系。**以你控制台里显示的实时价目为准。**

按我们实测的 token 量（39.6 输入 + 7.4 输出/句）折算，`mimo-v2.5` 单句约 **0.00004 元**，
每月一万句约 **0.4 元**——和 DeepSeek 同属"可以忽略"的量级，**价格不是选型决定因素**。

## 4. 与 DeepSeek 的关系（一句话）

- **单价**：小米 `mimo-v2.5` 输入 0.7 元 < DeepSeek `deepseek-flash` 1 元（空闲）/ 2 元（高峰）；
- **速度**：软件内实测 **DeepSeek 中位 1590 ms vs 小米 2553 ms**，DeepSeek 快 56~61%；
- 所以：**默认 DeepSeek，小米作为备选**（便宜一点、可在某家限流时顶上）。

## 5. 本文件的测试口径

- 第 1 节"能否调用"与第 2 节延迟均为**旁路直连 API**（PowerShell → `/v1/chat/completions`），
  每句一个目标语言、关闭思考、`temperature=0.1`；
- **它只回答"哪个模型更快/可用"**，不代表软件内端到端体验——那个见
  `docs/翻译服务软件内实测对比.md`（每句两次调用、计时到 OSC 报文）。
- 局限：每模型仅 3 句样本、单机单时段；pro 的官方单价未查证。
