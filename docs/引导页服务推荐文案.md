## 5. 为什么删掉了这些（避免以后有人再加回来）

| 删掉的内容 | 理由 |
| --- | --- |
| 阿里云的付费价格（60 元/百万字符） | 用户：**太贵，不值得**。免费额度用完就该换大模型，而不是掏钱 |
| 腾讯云的付费价格（58 元/百万字符） | 同上 |
| 小米 MiMo 行 | 用户：不值得列。延迟最慢（696 ms）、不是出厂预设。**资费已实测更正，见 §7** |
| 两个 pro 模型行 | 用户：**不值得列出来**。实测也支持：DeepSeek-V4-Pro 慢 83% 且全量质量更低；小米 Pro 几乎同速但全量略低 |
| 大模型的资费数字 | 用户只要「精确到模型名」，资费写「无，按 tokens 充值使用」即可；详细换算见 §7 与实验报告 |

**结论一句话**：机翻两家**只用免费额度**（付费比大模型贵约 24 倍）；要大模型就直接用 `deepseek-flash`。

## 7. 小米 MiMo v2.5 真实资费（用户 2026-02 从控制台提供，替换我之前的估算）

**官方价目（人民币）**：

| 项 | 价格 |
| --- | ---: |
| 输入（缓存命中） | ¥ 0.02 / 百万 tokens |
| 输入（缓存未命中） | ¥ 1 / 百万 tokens |
| 输出 | ¥ 2 / 百万 tokens |

我之前按公开报道写「输入 0.7 元、输出按输入 4 倍估成 2.8 元」——**两个数都不对**，已按上表更正。

**换算成与机翻同口径（元/百万字符）**：

| 模型 | 输入未命中 | 输入命中缓存 | 25 字单句成本 |
| --- | ---: | ---: | ---: |
| 小米 MiMo v2.5 | 2.5 元 | 0.9 元 | 0.000062 元 |
| deepseek-flash（空闲） | 3.3 元 | — | 0.000083 元 |
| deepseek-flash（高峰） | 6.7 元 | — | 0.000167 元 |
| 机翻（阿里云 专业版，对照） | 60 元 | — | 0.001500 元 |

结论：**小米 v2.5 比 deepseek-flash 便宜约 1.3 倍，比机翻便宜约 24 倍**；
而且系统提示词每次都一样，实际会命中缓存，输入部分只按 0.02 元计——真实成本比上表还低。

**要不要把小米加回引导页表格？** 加回去就是 5 行。它延迟最慢（696 ms，P90 达 1488 ms），
但**最便宜且不是唯一的大模型选择**。等你一句话：加 / 不加。
