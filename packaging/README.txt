VRCTranslate v1.1.23

系统要求
Windows 10 2004（Build 19041）或更高版本，64 位系统。
程序自带所需运行库和本地语音模型，无需另外安装 .NET。

启动
1. 完整解压压缩包，不要直接在压缩包内运行。
2. 双击根目录的 VRCTranslate.exe。“app”目录必须与它放在一起，不要单独移动 EXE。
3. 在“翻译”页面添加并配置自己的翻译服务，手动输入和本地/腾讯按句识别的译文使用这里。
4. 要把自己的输入或语音译文发送到 VRChat，请在游戏内开启 OSC。
5. 在“语音”页选择识别方式：
   - 本地识别：离线、免费，默认；
   - 阿里云实时翻译：Qwen3.8，中/英/日/韩，流式返回原文、简体中文译文和说话人 A/B，自带翻译，不需要在“翻译”页配置翻译模型；需要 DashScope API Key 和 Workspace ID；
   - 腾讯云按句识别：一句话识别，非流式，中/英/日/韩/粤，5000 次/月免费，超出 3.2 元/千次；只负责识别文字，译文仍走“翻译”页。
   云端识别只影响其他玩家，自己的麦克风始终使用本地模型。

数据
设置、翻译服务密钥、窗口位置和声纹数据保存在根目录的 data 文件夹。
新解压的软件不会读取或复制其它安装目录中的配置与密钥。
阿里云 API Key 用 Windows DPAPI 加密保存在 data\v2-qwen-asr.json；腾讯云 SecretKey 保存在 data\v2-tencent-asr.json。
他人语音识别与翻译只显示在本地字幕窗口，不会发送到 VRChat。
默认语音识别在本机完成；只有主动启用阿里云实时翻译或腾讯云按句识别时，其他玩家的音频才会分别发送到对应服务商。声纹仍只保存在本机。云端失败会自动回退本地。

说明
本软件不包含 OCR。需要截图翻译时可使用 QQ 的 Ctrl+Alt+F 等现成工具。
软件当前未进行数字签名，Windows 可能显示“未知发布者”。
