## 5. 大模型档的价格是怎么算出来的（实测口径，不是抄文案）

**实测**：拿 5 句真实评测句直接调 DeepSeek，读返回体里的 `usage`：

| 句子字符数 | prompt tokens | completion tokens |
| ---: | ---: | ---: |
| 23 | 44 | 16 |
| 16 | 36 | 8 |
| 10 | 34 | 6 |
| 66 | 43 | 10 |
| 22 | 46 | 8 |

→ 固定开销约 **30 tokens**（系统提示），内容约 **0.6 tokens/字符**。

**官方价目**（[DeepSeek 价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)，`deepseek-flash`）：
输入 1 元/百万 tokens（空闲）/ 2 元（高峰），输出 4 元/百万 tokens（空闲）/ 8 元（高峰）。

**换算结果**（含固定开销，所以句子越短每百万字符越贵）：

| 句长 | DeepSeek 空闲 | DeepSeek 高峰 | 小米 MiMo |
| ---: | ---: | ---: | ---: |
| 10 字符 | 6.2 元/百万字符 | 12.5 | 4.4 |
| 20 字符 | 4.7 元/百万字符 | 9.5 | 3.3 |
| 30 字符 | 4.2 元/百万字符 | 8.5 | 3.0 |
| 50 字符 | 3.8 元/百万字符 | 7.7 | 2.7 |

取整后写进表里的是 **DeepSeek 5 元、小米 3 元**（按 VRChat 常见句长 15~25 字符、空闲时段偏保守取整）。

**单句成本对照**（25 字符一句）：DeepSeek 0.000111 元、小米 0.000078 元、机翻 0.001375 元。
→ 大模型**比机翻便宜 12~18 倍**。

## 6. 取舍说明

| 决定 | 原因 |
| --- | --- |
| 表格而不是三行推荐 | 用户要求：让用户按「快 / 准 / 便宜」自己判断，推荐只做兜底 |
| 延迟只写翻译服务本身 | 用户要求：VAD 与本地识别不是选服务的原因，以后还会改 |
| 表现列压到 ≤20 字 | 用户要求：砍的是这部分字数，不是砍行数（5 行保留） |
| 表里零模糊词 | 用户要求：「同上 / 共用 / 约」这类词一律不出现，AI 读不懂、人也要多想一步 |
| 大模型价格写 5 / 3 元而不是区间 | 区间（如 4~12 元）在表格里无法比较；用「每百万字符」统一口径后即可与机翻同列比较 |
| 「粤语不翻译」不写成「粤语支持差」 | 前者是事实（原样退回），后者是模糊评价 |
