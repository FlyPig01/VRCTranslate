# 五家翻译服务全量实测（2026-09-16）

> **数据来源说明（2026-09-16 补记）**：本文是**小型原始记录**——每语种仅 1 句、每服务 5 次采样，
> 没有数学质量指标，也没有统计检验。**结论已被《[实验报告-识别与翻译.md](实验报告-识别与翻译.md)》取代**：
> 那份用了 27 条评测集 × 5 引擎 × 4 轮交错调用，质量用 chrF2/BLEU-4，延迟做了 Wilcoxon 配对检验。
> 本文保留的价值是：**每家的原始回复文本**（可对照新报告核对自己关心的句子）。
> 两处已被新数据修正的说法：① 「粤语原样退回不算 bug」——新实验证明大模型能译且 chrF2 93.6，
> 所以粤语场景应当**引导用户切大模型档**，而不是默默退回；② 本文的延迟数字是 5 次采样的点估计，
> 新报告的 108 次配对数据更可靠（腾讯 220 ms、阿里专业 195 ms、阿里通用 269 ms、DeepSeek 495 ms、小米 696 ms）。

目的：为"识别他人语音（语种不确定）"这条链路选定服务，并把**每一家**的实测结果集中记录，便于查阅。

- **口径**：直连各服务官方 API，**不是**软件内端到端。每句 = 单次调用、目标语言固定简体中文、关闭思考模式。
- **密钥**：全部为用户提供的**真实密钥**（腾讯 / 阿里取自 `config.json`，DeepSeek 取用户目录，小米由用户提供）。
- **样本**：日语 / 韩语 / 英语 / 粤语 / 繁体中文 各 1 句（VRChat 口语场景）。
- **明细数据**：`artifacts/all-providers-results.json`（25 条）、`artifacts/latency-results.json`（5 次采样）。
- 交叉引用：软件内端到端对比见《翻译服务软件内实测对比》，小米模型选型见《小米MiMo模型清单与选型》。

**检测能力**：腾讯与阿里都会在响应里回 `Source`/`DetectedLanguage`（ja/ko/en/zh/zh-tw），
小米与 DeepSeek 由模型自行判断、无独立字段。**两家机翻都只认"中文"，不认粤语**——粤语与繁体中文会被当成简体中文原样退回。

> 用户结论（2026-09-16）：**这不是 bug**。软件面向中文用户，粤语识别成中文后**原样显示即可**，
> 而且"识别成中文就不再调用翻译服务"反而是一次净提速（见第 3 节）。

## 2. 延迟：自动识别 vs 显式指定语种（各 5 次采样，日语同句）

| 服务 | `SourceLanguage=auto` 中位 | 显式传语种 中位 | 差额 |
| --- | --- | --- | --- |
| 腾讯云 | **270 ms** | 212 ms | 省 58 ms |
| 阿里云通用 | 297 ms | 272 ms | 省 25 ms |
| 阿里云专业 | **192 ms** | 262 ms | -70 ms（抖动） |
| DeepSeek | 526 ms | 517 ms | 省 9 ms |
| 小米 MiMo | 697 ms | 716 ms | -19 ms（抖动） |

**结论：显式传语种的收益只有 25~58 ms，落在抖动范围内，不值得为此增加映射表与误判风险。**
（早期 3 次采样曾得出"省 166 ms"与"小米 5767 ms"两个结论，均已用 5 次采样复核并撤回——单次/少量采样不可靠。）

**速度排序（日语，自动识别）**：阿里云专业 192 ms ≈ 腾讯云 270 ms ≈ 阿里云通用 297 ms
→ DeepSeek 526 ms → 小米 697 ms。**传统机翻比大模型快 2~3 倍**，适合逐句字幕。

## 3. 推荐（按"他人语音字幕"这个场景）

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 对方说中文 / 粤语 | **不调用任何翻译服务**（识别成中文就原样显示） | 省 200~900 ms 的整次往返，且避免"粤语被当中文"的误译风险 |
| 对方说日 / 韩 / 英 | **腾讯云或阿里云机翻**（默认 auto） | 200~300 ms，比大模型快 2~3 倍；两家都支持自动识别 |
| 对方说粤语且需要真翻译 | 大模型（DeepSeek / 小米） | 只有大模型能真正翻粤语 |
| 对方说繁体中文 | 阿里云（能检测 zh-tw 并转简体）或大模型 | 腾讯会把繁体当简体原样退回 |

## 5. 局限

- 每种语种**仅 1 句样本**（质量结论只看"是否翻对、有无明显瑕疵"，不做统计比较）；
- 延迟为**直连 API**，不含软件内的 VAD（600 ms 静音判定）与 OSC 发送；
- 未测：德语/法语/西语等（SenseVoice 本地识别不支持，链路也走不到）、长文本、并发；
- 网络抖动明显（同一句 150~567 ms 波动），**所有延迟结论都应看中位数而非单次**。
