# 作者小店入口：怎么配链接

> 状态：**功能已实施**（提交见仓库），出厂**不显示**——填了链接才出现。
>
> 用途：在「指南」页展示作者的闲鱼小店（VRChat 模型 / 工程文件 / 素材）。
> 原则：**软件本身免费开源**，小店是作者自己的东西，两者分开展示，不放进输入条或字幕浮窗。

## 1. 怎么填（不用改代码、不用重新编译）

在软件的**数据目录**里编辑 `v2-user-settings.json`，加一行 `ShopUrl`：

```json
{
  "QuickInputHotkey": "Ctrl+Alt+I",
  "VoiceHotkey": "F7",
  "SelfVoiceHotkey": "Ctrl+F8",
  "OscHost": "127.0.0.1",
  "OscPort": 9000,
  "OscIntervalSeconds": 1.5,
  "PlaySound": true,
  "KeepRunning": true,
  "ShopUrl": "https://www.goofish.com/personal?userId=你的ID"
}
```

保存后**重新打开指南页**即可看到卡片（每次进页面都重读，不必重启软件）。想撤下就删掉 `ShopUrl` 这一行，卡片立刻折叠。

### 数据目录在哪

按优先级（`PortableStorage.Select`）：

| 情况 | 目录 |
| --- | --- |
| 设置了环境变量 `VRC_TRANSLATE_DATA_DIR` | 该目录（冒烟测试用） |
| exe 旁边有可写的 `data` 文件夹（**手测包就是这种**） | `artifacts\manual-test\data\` |
| exe 所在目录只读（装在 Program Files 等） | `%LOCALAPPDATA%\VRCTranslate\` |

**手测包**：`E:\MyTools\VRCTranslate\artifacts\manual-test\data\v2-user-settings.json`

## 2. 卡片长什么样

```
┌─ 作者的小店 ───────────────────────────────────────┐
│ 软件本身免费开源、功能不收费。作者在闲鱼出售 VRChat   │
│ 模型、工程文件与素材，感兴趣可以看看；不看也不影响使用。│
│ 在闲鱼打开作者的小店 →                             │
└──────────────────────────────────────────────────┘
```

位置：指南页最下方（在「模型对比」卡片下面）。

## 3. 三条安全规则（写进了校验脚本，改坏会构建失败）

| 规则 | 原因 |
| --- | --- |
| 链接**只能**来自用户配置，XAML 里不得写死 `goofish` / `2.taobao` 链接 | 换店铺、临时下架都不用改代码；也避免把外链硬编码进界面 |
| 文案必须包含「软件本身免费开源」 | 防止看起来像「付费才能用」——那是这个功能唯一的风险 |
| 链接必须是 `http` / `https`，其它协议（含 `javascript:`）一律折叠卡片 | 配置写错时宁可什么都不显示，也不要摆一个坏链接或危险链接 |

## 4. 为什么不用「打赏」措辞

用户的实际场景是**卖模型/工程/素材**，不是求打赏。所以卡片叫「作者的小店」、写「出售」，
而不是「请我喝咖啡」。但同一条底线保留：**必须写明软件免费**，否则容易被当成二道贩子卖别人的开源软件。

## 5. 运行验证（已实测）

| 场景 | 结果 |
| --- | --- |
| 出厂状态（无 `ShopUrl`） | 卡片不可见 ✅ |
| 填了合法链接 | 卡片可见，且含「免费开源」文案 ✅ |
| 填了 `javascript:` 这类坏链接 | 卡片不可见 ✅ |

验证脚本：`artifacts/verify-shop-card.ps1`（用 UIA 读真实窗口文本，三种场景各跑一次）。

## 6. 还需要你提供的东西

**闲鱼店铺链接**。拿到后有三种做法，按你的偏好选：

1. **自己填**（推荐）：按 §1 改手测包里的 `v2-user-settings.json`，立刻生效，我什么都不用改；
2. **让我填进手测包**：你把链接发我，我写进 `artifacts/manual-test/data/v2-user-settings.json` 并重新验证；
3. **改出厂默认**：把链接写进代码里的默认设置——这样**每个新用户**都看到卡片。需要你明确同意，因为那等于给所有用户看商业入口。

目前出厂是**不显示**的（安全默认）。
