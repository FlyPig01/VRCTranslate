# v1.1.23

本次更新自最近发布 tag **v1.1.13** 起，包含腾讯云按句识别、字幕分块修复，以及阿里云 Qwen LiveTranslate 实时翻译。

## 新增

- **阿里云 Qwen3.8 LiveTranslate 实时翻译**
  - 实时返回原文、简体中文译文和说话人 A/B；
  - 支持中/英/日/韩，官方约 2.3 秒延迟；
  - 自带翻译，**不需要在翻译页配置翻译模型**；
  - 只使用 Windows 回环采集、音频电平和字幕浮窗，不调用本地 SenseVoice、VAD、pyannote 或 CAM++。
- **语音识别卡片**
  - 语音页改为“本地识别 / 阿里云实时翻译 / 腾讯云按句识别”三张卡片；
  - 点击卡片切换当前引擎，选中的卡片高亮；
  - 配置放在独立弹窗，不再把密钥和语言选项平铺在页面上。
- **Qwen 配置**
  - 支持 DashScope API Key、Workspace ID、北京/新加坡地域；
  - API Key 使用 Windows DPAPI 加密保存到 `data\v2-qwen-asr.json`；
  - 保存前可测试连接，测试失败不会启用云端。
- **云端失败回退**
  - Qwen 连接失败时提示一次，并回退本地识别。
- **腾讯云按句识别**
  - 一句话识别（非流式），支持中/英/日/韩/粤；
  - 5000 次/月免费，超出 3.2 元/千次；
  - 仍使用本地 VAD 和本地声纹标签，文字识别交给腾讯云。

## 此前未发布、本次一并包含

- 腾讯云一句话识别与语音页配置；
- 指南补充腾讯云按句的额度、价格和配置说明；
- 字幕按 VAD 段独立分块，同说话人的连续句子不再合并成一大段；
- 去掉顶部单独的“识别中”临时行，识别状态只由字幕内容体现；
- 修复 Qwen 之前腾讯实时路径的若干字幕时序问题；腾讯实时路径现已移除。

## 修复

- 修复 Qwen 中间态字幕只显示几个字的问题：
  - `delta` 事件改为累加，不再用最新一段覆盖整段原文；
  - `text` 事件使用确认文本 + stash；
  - `completed` 使用最终完整原文。
- 修复 Qwen 字幕重复新建块：
  - 同一段原文/译文按 item id 在原字幕块内更新；
  - 不再每来一个增量就新增一条消息。
- 修复腾讯按句识别配置入口丢失的问题。

## 行为变化

- **腾讯云实时识别已移除**：旧实时配置不会再进入识别路径；腾讯云按句保留。
- 本地模式、腾讯按句模式仍使用本地切句和本地说话人标签。
- 阿里云 Qwen 模式的 A/B 来自云端 `speaker_id`，不写入本地声纹库。
- Qwen 的说话人标记暂不支持自定义命名，仅显示 A/B。
- Qwen 模式不需要翻译页的翻译模型；腾讯按句和本地模式仍需要。

## 安装

下载 `VRCTranslate-v1.1.23-win-x64.zip`，解压后运行 `VRCTranslate.exe`。

正式包不包含 `data\`、API Key 或本机配置。

## 已知限制

- 阿里云 Qwen 需要百炼 API Key 和 Workspace ID，且当前使用华北 2（北京）或新加坡地域；
- Qwen 的说话人 A/B 为会话内标识，跨会话不保证稳定；
- 腾讯云按句为非流式，延迟高于实时模式；
- 云端服务价格与额度以服务商官网为准。
